## Goal
Make a corrected procedure reusable and run it only when intended: after `bridgeQuest.bridgeReady`, a **منصة المهارة** and **ساعة الحي** unlock in the same workshop. The player runs a one-shot hall-hours summary, sees it invent a minute, corrects it, then saves a stored procedure with trigger, inputs, steps, output and stop — not a standing chat constitution, not MCP, not a one-off command. That skill is tested on an independent second record. The same skill is then armed on the in-game clock, observed to fire, paused, and shown not to run. Covers **5.5 and 5.6**.
